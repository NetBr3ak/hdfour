# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:
open **Security**, then **Report a vulnerability**. Do not post a vulnerability,
exploit or sensitive file in a public issue or pull request.

Include the affected revision, the command that reproduces the problem and the
expected result. Share only files you have permission to disclose. If possible,
use a small synthetic file without personal or confidential data.

Private vulnerability reporting must be enabled before this repository opens
to outside contributors. Until then, use the repository's private vulnerability
and conduct reporting.

## Release status

No version has been published. There is no supported release series yet.
